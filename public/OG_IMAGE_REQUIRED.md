# OG Image Required

Create `og-default.png` (1200x630px) in this directory.

This image is used as the default Open Graph and Twitter Card image across all pages.
Design guidelines:
- Background: #11100E (dark)
- Logo/brand text: IoTMart in #F0C060 (gold)
- Tagline: "Nepal's IoT Hardware Store"
- Dimensions: exactly 1200 × 630 pixels
- Format: PNG
- File size: < 300KB

Also create:
- `logo.png` (200x60px) — used in Organization JSON-LD schema
- `apple-touch-icon.png` (180x180px) — for iOS home screen
